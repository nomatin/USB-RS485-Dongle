# Техническое задание
## На разработку преобразователя интерфейсов USB–RS485

## 1. Общие сведения

### 1.1. Наименование изделия

Преобразователь интерфейсов USB 2.0 — RS-485 с гальванической развязкой.

### 1.2. Назначение

Изделие предназначено для подключения персональных компьютеров, промышленных контроллеров и других устройств, оснащённых интерфейсом USB, к оборудованию с интерфейсом RS-485.

Основные области применения:

- Наладка и диагностика промышленного оборудования.
- Работа с устройствами Modbus RTU и Modbus ASCII.
- Разработка и испытание электронной аппаратуры.
- Подключение датчиков, контроллеров и других устройств RS-485.

### 1.3. Основные особенности

- Гальваническая развязка USB и RS-485.
- Питание непосредственно от USB без внешнего источника.
- Автоматическое управление направлением передачи.
- Поддержка полудуплексной двухпроводной линии RS-485.
- Отключаемое согласование линии.
- Разъём DE-9 с распиновкой согласно Modbus Serial Line Specification V1.02.
- Индикация питания, передачи и приёма данных.

## 2. Функциональные требования

| ID | Требование |
|---|---|
| FR-01 | Изделие должно обеспечивать двунаправленную передачу данных между USB и RS-485. |
| FR-02 | Устройство должно определяться компьютером как виртуальный последовательный порт (Virtual COM Port). |
| FR-03 | Управление направлением RS-485 должно осуществляться автоматически, без ручного переключения. |
| FR-04 | Должна поддерживаться настройка скорости передачи, числа бит данных, проверки чётности и стоповых битов. |
| FR-05 | Устройство должно обеспечивать подключение и отключение согласующей цепи линии RS-485. |
| FR-06 | Должна быть предусмотрена светодиодная индикация питания, передачи TX и приёма RX. |
| FR-07 | Устройство должно сохранять корректное состояние интерфейсов при подключении, отключении и повторном подключении USB. |
| FR-08 | Устройство должно поддерживать работу с Modbus RTU/ASCII на уровне прозрачной передачи последовательных данных. Реализация протокола Modbus внутри преобразователя не требуется. |

## 3. Требования к интерфейсам

### 3.1. Интерфейс USB

| Параметр | Требование |
|---|---|
| Стандарт | USB 2.0 |
| Разъём | USB Type-C |
| Режим | USB Device |
| Тип устройства | USB–UART Bridge |
| Питание | От шины USB, номинально 5 В |

Должна обеспечиваться возможность использования устройства в Windows и Linux. Поддержка macOS допускается при наличии совместимого драйвера.

Подключение к компьютеру не должно требовать разработки специализированного пользовательского программного обеспечения.

### 3.2. Интерфейс RS-485

| Параметр | Требование |
|---|---|
| Электрический интерфейс | TIA/EIA-485 |
| Режим обмена | Полудуплексный |
| Конфигурация | 2-wire, A/B и Common |
| Скорость UART | От 300 до 3 000 000 бод |
| Управление направлением | Автоматическое |
| Согласующая цепь | Отключаемая |
| Разъём | DE-9 female |
| Гальваническая развязка | Обязательна |

Передача и приём должны осуществляться по одной дифференциальной паре проводников.

В режиме отсутствия передачи выходной драйвер не должен препятствовать обмену между другими устройствами линии.

### 3.3. Назначение контактов DE-9

Распиновка должна соответствовать обязательным цепям двухпроводного интерфейса, описанным в Modbus over Serial Line Specification and Implementation Guide V1.02, раздел 3.5.1.

| Контакт | Сигнал | Назначение |
|---|---|---|
| 1 | Common | Общий провод изолированной стороны |
| 5 | D1 (B) | Дифференциальная линия D1 |
| 9 | D0 (A) | Дифференциальная линия D0 |
| Остальные | NC | Не используются |

Необходимо сохранить предусмотренную спецификацией полярность D0/D1 независимо от обозначений выводов конкретной микросхемы.

Передача питания по контакту VP не предусматривается.

### 3.4. Терминация RS-485

Изделие должно содержать отключаемую цепь согласования линии RS-485.

Требования:

- Переключение выполняется механическим переключателем на плате.
- Переключатель должен быть доступен пользователю снаружи корпуса.
- Согласующая цепь должна размещаться вблизи выходного разъёма.
- В отключённом положении согласующая цепь не должна нагружать линию.
- Состояния переключателя должны иметь маркировку ON/OFF.

## 4. Требования к электрической безопасности и защите

### 4.1. Гальваническая развязка

Изделие должно содержать гальваническую развязку между цепями USB и RS-485.

Не допускается прямое гальваническое соединение сигнальных общих проводов первичной и изолированной сторон.

Развязка должна распространяться на информационные цепи и цепи питания.

Применяемая элементная база должна обеспечивать паспортную электрическую прочность изоляции не менее 5 кВ RMS при условиях испытаний изготовителя компонентов.

### 4.2. Защита интерфейсов

Необходимо предусмотреть:

- Защиту USB от электростатических разрядов.
- Защиту входных/выходных цепей RS-485 от внешних электрических воздействий.
- Защиту цепей питания от недопустимых переходных процессов.
- Исключение недопустимых режимов при подключении и отключении кабелей.

## 5. Требования к электропитанию

- Питание устройства должно осуществляться от USB VBUS 5 В.
- Применение отдельного внешнего блока питания не допускается.
- Питание изолированной части должно формироваться внутри устройства.
- Потребление тока должно соответствовать ограничениям выбранной конфигурации USB.
- Должен быть предусмотрен корректный режим приостановки USB (Suspend), включая управление питанием изолированной части.
- Включение и отключение изолированного преобразователя питания должно осуществляться управляемым сигналом с определённым состоянием при запуске.

## 6. Требования к конструкции

### 6.1. Печатная плата

- Конструкция — единая печатная плата.
- Монтаж преимущественно поверхностный, THT допускается для механически нагруженных компонентов.
- Разъёмы должны иметь достаточную механическую прочность для многократного подключения кабелей.
- Размещение компонентов должно учитывать требования электрической изоляции и электромагнитной совместимости.
- На плате должны быть обозначены интерфейсы, ревизия, а также положения переключателя терминации.

### 6.2. Корпус

Для устройства предусматривается защитный корпус.

Корпус должен обеспечивать:

- Защиту компонентов от случайного механического воздействия.
- Доступ к USB и DE-9.
- Доступ к переключателю терминации.
- Возможность наблюдения за светодиодами.
- Фиксацию платы без повреждения электрических компонентов.

## 7. Требования к документации

### 7.1. Конструкторская документация по ЕСКД

В составе проекта необходимо разработать:

1. Техническое задание.
2. Схему электрическую принципиальную (Э3).
3. Перечень элементов (ПЭ3).
4. Чертёж печатной платы.
5. Сборочный чертёж печатного узла.
6. Спецификацию.
7. Программу и методику испытаний.

Конструкторская документация должна разрабатываться в соответствии с применимыми стандартами ЕСКД.

### 7.2. Производственная документация

Для изготовления и монтажа печатной платы необходимо подготовить:

1. **BOM** — ведомость компонентов для закупки и комплектации производства.
2. **Gerber** — комплект файлов изготовления печатной платы.
3. **Drill** — файлы сверления.
4. **Pick-and-Place** — файлы координат установки компонентов для автоматизированного монтажа.

### 7.3. Исходные файлы проекта

В состав проекта должны входить исходные файлы САПР:

- Электрическая принципиальная схема.
- Проект печатной платы.
- Используемые проектные библиотеки или необходимые для восстановления проекта компоненты.

Исходные файлы, документация и производственные данные должны храниться в системе контроля версий Git.

## 8. Требования к проверке и испытаниям

| ID | Испытание | Критерий приёмки |
|---|---|---|
| VT-01 | Подключение к USB | Устройство определяется операционной системой |
| VT-02 | Работа VCP | Создание и открытие последовательного порта |
| VT-03 | Передача TX | Корректная передача тестовых данных |
| VT-04 | Приём RX | Корректный приём тестовых данных |
| VT-05 | Полудуплекс | Автоматическое освобождение линии после передачи |
| VT-06 | Проверка скоростей | Работа на контрольных скоростях UART |
| VT-07 | Терминация | Переключение и измерение параметров согласующей цепи |
| VT-08 | Гальваническая развязка | Отсутствие прямой проводящей связи между общими проводами USB и RS-485 |
| VT-09 | Индикация | Корректная работа PWR, TX, RX |
| VT-10 | USB Suspend | Корректная реакция на приостановку и возобновление работы USB |
| VT-11 | Длительный обмен | Отсутствие потерь и искажений данных в заданном тесте |
| VT-12 | Modbus RTU | Успешный обмен между ПК и заведомо исправным устройством Modbus RTU |

Контрольные скорости для VT-06: 9600, 115200, 921600 и 3000000 бод.

Подробные условия, оборудование, последовательность действий и критерии оценки должны быть установлены в программе и методике испытаний.

## 9. Порядок разработки

Работы выполняются в следующей последовательности:

1. Выбор и проверка компонентной базы.
2. Разработка электрической принципиальной схемы.
3. Проверка схемы и проведение необходимых расчётов.
4. Разработка топологии печатной платы.
5. Проверка DRC и выпуск производственной документации.
6. Изготовление и монтаж опытного образца.
7. Проведение испытаний.
8. Устранение выявленных замечаний.
9. Выпуск окончательного комплекта конструкторской документации.
