# USB–RS485 Dongle

**USB 2.0 ↔ RS-485 · Гальваническая развязка · Altium Designer · T-FLEX CAD**

Компактный преобразователь USB–RS485 с питанием от USB, предназначенный для подключения компьютера к двухпроводной сети RS-485. Проект охватывает разработку электрической схемы, печатной платы, механической конструкции корпуса и подготовку документации для изготовления. В качестве сценариев применения рассматриваются наладка и диагностика датчиков, контроллеров и оборудования с Modbus RTU/ASCII.

> **Статус:** проектирование платы и корпуса завершено, исходные файлы и производственная документация опубликованы. Изготовление и испытания опытного образца в репозитории пока не подтверждены. Перечисленные ниже скорости и функции — проектные требования, а не результаты измерений.

**Быстрая навигация:** [Электроника и PCB](Board/README.md) · [Корпус и сборка](Case/README.md) · [Конструкторская документация](Docs/) · [Техническое задание](Docs/USB_RS485_TZ.md)

## Ключевые характеристики

| Параметр | Проектное решение / требование |
| --- | --- |
| Подключение к ПК | USB 2.0, разъём USB Type-C, режим USB Device |
| USB–UART | Silicon Labs CP2102N-A02-GQFN24, виртуальный COM-порт (VCP) |
| RS-485 | Двухпроводный полудуплекс, линии D0/D1 и Common |
| Изолированный интерфейс | TI ISOW1432DFMR с развязкой сигналов и встроенным изолированным питанием |
| Питание | От шины USB, номинально 5 В |
| Диапазон скоростей UART | 300–3 000 000 бод (целевой) |
| Управление передачей | Автоматическое переключение направления (предусмотрено проектом) |
| Подключение линии | DE-9 female |
| Терминация | Отключаемое согласование линии |
| Индикация | Питание, TX, RX |
| Целевые ОС | Windows и Linux |

Преобразователь передаёт последовательные данные прозрачно: протокол Modbus RTU/ASCII реализуется на стороне подключённых устройств или программы на ПК, а не внутри адаптера.

## Архитектура

```mermaid
flowchart LR
    PC["Компьютер"] <-->|"USB 2.0"| CP["CP2102N<br/>USB–UART"]
    CP <-->|"UART и управление направлением"| ISO["ISOW1432<br/>Изоляция данных<br/>Изолированное питание"]
    ISO <-->|"RS-485"| DB["DE-9<br/>D0 / D1 / Common"]
```

Выбранный ISOW1432 содержит изолированный интерфейс и встроенный преобразователь питания. Электрическая реализация двухпроводного подключения и управления передатчиком приведена в [исходной схеме](Board/SCH/UARTtoRS485.SchDoc).

### Подключение RS-485

Назначение контактов DE-9 в проекте соответствует принятой в техническом задании распиновке Modbus Serial Line:

| Контакт DE-9 | Сигнал | Назначение |
| --- | --- | --- |
| 1 | Common | Общий провод изолированной стороны |
| 5 | D1 (B) | Дифференциальная линия D1 |
| 9 | D0 (A) | Дифференциальная линия D0 |
| Остальные | NC | Не задействованы |

Питание через DE-9 не передаётся. При подключении сверяйте обозначения D0/D1 и A/B с документацией второго устройства: маркировка A/B не у всех производителей однозначна. Терминацию включают в зависимости от положения адаптера в линии.

## Как использовать материалы

1. Откройте [проект Altium Designer](Board/USB_to_RS485.PrjPcb) и изучите [документацию платы](Board/README.md).
2. Для изготовления платы используйте опубликованные производственные файлы, предварительно сверив их с актуальной ревизией PCB и требованиями выбранного производителя.
3. Для механической части откройте [сборку в T-FLEX CAD](Case/CAD/Assembly.grb) и [документацию корпуса](Case/README.md).

**Важно:** опубликованный комплект предназначен прежде всего для ознакомления с инженерной разработкой. До подтверждения результатов испытаний не следует считать заявленные характеристики, уровень защиты и работу устройства в целом экспериментально проверенными.
