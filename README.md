# USB–RS485 Dongle

Преобразователь USB 2.0 ↔ RS-485 с гальванической развязкой данных и питания. Предназначен для подключения компьютера к оборудованию с интерфейсом RS-485, включая устройства Modbus RTU/ASCII.

Проект включает электрическую схему, печатную плату, корпус и комплект конструкторской документации по ЕСКД.

## Основные характеристики

| Параметр | Значение |
|---|---|
| USB | USB 2.0 Type-C |
| USB–UART | CP2102N-A02-GQFN24 |
| RS-485 | ISOW1432DFMR |
| Режим | Двухпроводный полудуплекс |
| Скорость UART | 300–3 000 000 бод |
| Управление направлением | Автоматическое |
| Гальваническая развязка | Данных и питания |
| Питание | От USB, 5 В |
| Разъём RS-485 | DE-9 female |
| Терминация | Отключаемая |
| Индикация | PWR, TX, RX |

## Разработка

Электрическая схема и печатная плата разработаны в **Altium Designer** с использованием собственной библиотеки компонентов [ESKD Altium Libraries](https://github.com/nomatin/ESKD-altium-libraries).

Для выпуска конструкторской документации по ЕСКД применялся GOST BOM с собственным набором исправлений [GOSTBOM-Fixes](https://github.com/nomatin/GOSTBOM-Fixes).

Корпус разработан в **T-FLEX CAD** из плоских деталей для упрощения мелко- и среднесерийного производства. Изготовление деталей из листового материала быстрее 3D-печати и не требует дорогостоящей оснастки для литья. Внешний вид корпуса намеренно уступил технологичности и стоимости производства.
