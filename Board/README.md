# Печатная плата преобразователя USB–RS485

Плата разработана в **Altium Designer**. Она преобразует USB 2.0 в двухпроводной полудуплексный RS-485 с гальванической развязкой данных и питания. Питание подаётся через USB Type-C, линия RS-485 подключается через DE-9.

USB–UART-мост **CP2102N-A02-GQFN24** обеспечивает работу через виртуальный последовательный порт. Изолированный приёмопередатчик **ISOW1432DFMR** подключает UART к линии RS-485. На плате предусмотрены автоматическое управление направлением передачи, отключаемое согласование линии и светодиодная индикация питания, TX и RX.

## Проект Altium Designer

Откройте [USB_to_RS485.PrjPcb](USB_to_RS485.PrjPcb), чтобы работать со схемой и [топологией платы](PCB/PCB.PcbDoc). Схема состоит из трёх листов:

- [MAIN](SCH/MAIN.SchDoc) — верхний уровень проекта и связи между узлами.
- [USBtoUART](SCH/USBtoUART.SchDoc) — интерфейс USB и преобразование в UART.
- [UARTtoRS485](SCH/UARTtoRS485.SchDoc) — изолированный интерфейс RS-485.

Исходники чертежей платы и сборки находятся в [Drawings/](Drawings/). Настройки выпуска документации и производственных файлов сохранены в [Schematics.OutJob](OutJob/Schematics.OutJob).
