# Электроника и печатная плата

[← На главную](../README.md) · [Корпус](../Case/README.md) · [Техническое задание](../Docs/USB_RS485_TZ.md)

Раздел электрической части преобразователя USB–RS485. Разработка выполнена в **Altium Designer**: от иерархической схемы и трассировки до чертежей по ЕСКД и файлов для изготовления платы.

**Статус:** схема и топология разработаны; производственные файлы экспортированы. Работа изготовленного устройства и заявленные электрические параметры пока не подтверждены опубликованными испытаниями.

## Функциональные узлы

| Узел | Компонент / назначение |
| --- | --- |
| USB и UART | **CP2102N-A02-GQFN24** — мост USB–UART для работы через виртуальный COM-порт |
| Изолированный RS-485 | **ISOW1432DFMR** — гальваническая развязка сигнальных цепей и встроенное изолированное питание |
| Интерфейс компьютера | USB Type-C, USB 2.0 |
| Подключение линии | DE-9 female, двухпроводный RS-485 с Common |
| Вспомогательные цепи | Защита интерфейсов, переключаемое согласование линии, индикация питания, TX и RX |

Требование к диапазону скоростей — **300–3 000 000 бод**; его выполнение на реальной плате предстоит проверить.

### Особенности проектного решения

- **Гальваническая развязка:** интерфейс компьютера и полевая сторона RS-485 разделены; питание изолированной части формируется на плате. Электрическая прочность изоляции должна оцениваться по характеристикам компонента и конструкции платы, а не только по наличию микросхемы.
- **Двухпроводный RS-485:** схема рассчитана на полудуплексную шину. ISOW1432 — приёмопередатчик с отдельными каналами передачи и приёма; фактическое соединение и управление входами разрешения следует смотреть на листе [UARTtoRS485](SCH/UARTtoRS485.SchDoc).
- **Автоматическое направление:** это требование проекта. Для повторения сборки нужно проверить выбранную конфигурацию CP2102N и управление разрешением передачи; отдельный файл настроек CP2102N пока не опубликован.
- **Терминация:** предусмотрено включаемое согласование линии механическим переключателем. Использовать его следует в соответствии с топологией сети.
- **Защита и индикация:** в схеме предусмотрены защитные цепи и светодиоды PWR/TX/RX.

## Печатная плата и проверка

Проект рассчитан на двухслойную плату; для изготовления рассматривались **FR-4, толщина около 1,5 мм и медь 18 мкм**. Эти значения описывают проектный выбор технологии; перед заказом следует проверить актуальную конструкторскую документацию и стек слоёв в проекте.

В опубликованном [отчёте DRC](OUTPUT/Design%20Rule%20Check%20-%20PCB.drc) от **03.11.2026** указано **0 нарушений**. Он относится к состоянию проекта на дату проверки. Перед отправкой в производство рекомендуется перезапустить DRC и сравнить сгенерированные файлы с актуальной редакцией PCB.

## Предстоящие проверки

| Проверка | Что подтвердить |
| --- | --- |
| Подключение USB / VCP | Устройство определяется и создаёт последовательный порт |
| UART → RS-485 → UART | Передача и приём, отсутствие потерь данных |
| Автоматическое направление | Освобождение шины после завершения передачи |
| Скорости обмена | В том числе 9600, 115200, 921600 и 3000000 бод |
| Терминация | Корректное включение и отключение |
| Изоляция | Отсутствие прямого соединения общих проводов; дополнительные испытания — по утверждённой методике |
| Питание и USB Suspend | Токопотребление, переход в Suspend и возобновление |
| Modbus RTU | Обмен с проверенным устройством RS-485 |
